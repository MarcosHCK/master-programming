\subsection{Programa 1}

\subsubsection{Objetivos}

Este programa condensa varias clases, cuyos objetivos son:

\begin{enumerate}
  \item Sumar dos matrices de tamaño 2x2.
  \item Sumar y restar dos matrices de tamaño arbitrario, \(n\)x\(m\).
  \item Multiplicar dos matrices de tamaño arbitrario, \(n\)x\(m\) y \(m\)x\(k\).
\end{enumerate}

\subsubsection{Tecnicismos}

Arquitectura basada en \ref{sec:genarc:python}.

\subsubsection{Código relevante}

El núcleo del código contiene dos funciones, las cuales realizan las operaciones lineales (suma y resta) y la multiplicación, respectivamente

\begin{minted}{python3}

  def linear_operator (a: list[list[float]], b: list[list[float]], op: Callable[[float, float], float]):

    if len (a) != len (b):
      raise Exception (f'incompatible matrix sizes ({len (a)} against {len (b)} rows)')

    if len (a [0]) != len (b [0]):
      raise Exception (f'incompatible matrix sizes ({len (a [0])} against {len (b [0])} columns)')

    def do_cols (a: list[float], b: list[float]):

      for e1, e2 in zip (a, b):
        yield op (e1, e2)

    def do_rows (a: list[list[float]], b: list[list[float]]):
    
      for e1, e2 in zip (a, b):
        yield list (do_cols (e1, e2))

    return list (do_rows (a,  b))

  def matrix_product (a: list[list[float]], b: list[list[float]]):

    if len (a [0]) != len (b):
      raise Exception(f'incompatible matrix sizes ({len (a [0])} columns against {len (b)} rows)')

    def flip (m: list[list[float]]):

      for i in range (len (m [0])):
        yield list (( r [i] for r in b ))

    t = list (flip (b))

    def mul_abs (r: list[float], t: list[float]):

      for a, b in zip (r, t):
        yield a * b

    def mul_cols (r: list[float], t: list[list[float]]):

      for col in t:
        yield sum (mul_abs (r, col))

    def mul_rows (a: list[list[float]], t: list[list[float]]):

      for row in a:
        yield list (mul_cols (row, t))

    return list (mul_rows (a, t))

\end{minted}

\subsection{Programa 2}

\subsubsection{Objetivos}

Representar gráficamente una matriz de tamaño 2x2. Para ello, usar dicha matriz como una transformación del plano cartesiano.

\subsubsection{Tecnicismos}

Arquitectura basada en \ref{sec:genarc:python}.

\subsubsection{Código relevante}

El núcleo del código la generación de un cuadrado de lado unidad para determinar la transformación del plano:

\begin{minted}{python3}
  square = np.array ([[ 0, 0 ], [ 1, 0 ], [ 1, 1 ],
                      [ 0, 1 ], [ 0, 0 ]])
\end{minted}

Además, el código necesario para transformar dicho cuadrado y representarlo en el plano:

\begin{minted}{python3}

  # matriz inicial
  M = np.array ([[ 1.0, 0.0 ],
                 [ 0.0, 1.0 ]])

  transformed = (M @ square.T).T

  ax.plot (square [:, 0], square [:, 1], color = 'steelblue', lw = 2, label = 'Original')
  ax.fill (square [:, 0], square [:, 1], color = 'steelblue', alpha = 0.15)

  ax.plot (transformed [:, 0], transformed [:, 1], color = 'crimson', lw = 2, label = 'Transformed')
  ax.fill (transformed [:, 0], transformed [:, 1], color = 'crimson', alpha = 0.15)

\end{minted}

\subsection{Programa 3}

\subsubsection{Objetivos}

Este programa es una reescritura del \textbf{Programa 1} al lenguaje \textbf{C++}, con el fin de acomodar mejor las nuevas funcionalidades. Además de heredar los objetivos originales (suma, resta y multiplicación de matrices de tamaño arbitrario), añade las siguientes operaciones:

\begin{enumerate}
  \item Multiplicar a la derecha por la inversa, \(A \cdot B^{-1}\) (operador \mintinline{bash}{/}).
  \item Multiplicar a la izquierda por la inversa, \(B^{-1} \cdot A\) (operador \mintinline{bash}{%}).
\end{enumerate}

\subsubsection{Tecnicismos}

Arquitectura basada en \ref{sec:genarc:cplusplus}.

\subsubsection{Código relevante}

El núcleo del código contiene un despacho de operaciones que implementa tanto las operaciones lineales y la multiplicación originales, como las nuevas operaciones con la matriz inversa:

\begin{minted}{cpp}

  switch (op [0])
    {

    case '+': print_operation (A, B, op, MEASURE (A + B));
      break;

    case '-': print_operation (A, B, op, MEASURE (A - B));
      break;

    case '*': print_operation (A, B, op, MEASURE (A * B));
      break;

    case '/': print_operation (A, B, op, MEASURE (A * (B ^ inverse)));
      break;

    case '%': print_operation (A, B, op, MEASURE ((B ^ inverse) * A));
      break;

    default:
      throw wrap_stacktrace<std::invalid_argument> ("invalid operation " + op);
    }
\end{minted}
